## Featured Projects

### [Python Resume Parser — From 4 Hours to 20 Seconds](https://blog.abdultalha.tech/from-4-hours-to-20-seconds-saving-16-hoursweek-with-a-python-resume-parser)
A Python automation tool that parses and ranks 500+ resumes in 20 seconds using multiprocessing — saving a freelance client 16+ hours per week.  
**Stack:** Python · Multiprocessing · PyPDF2 · python-docx

### [Alzheimer's Detection — IEEE Published](https://github.com/abdultalha0862/Alzheimer-s-Disease-Detection-using-Deep-Learning)

**Stack:** Python · TensorFlow · Keras · CNNs

A web app that generates professional GitHub profile READMEs from form inputs — no Markdown knowledge needed.
