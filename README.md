**Technologies:** Python, Multiprocessing, PyPDF2, python-docx

### [AI/ML Alzheimer's Detection (IEEE Published)](https://github.com/abdultalha0862/Alzheimer-s-Disease-Detection-using-Deep-Learning)

**Technologies:** Python, TensorFlow, Keras, CNNs
